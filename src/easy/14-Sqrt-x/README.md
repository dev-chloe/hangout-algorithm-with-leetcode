# 메모 - [Sqrt(x)](https://leetcode.com/problems/sqrtx/)

> [대상 소스 코드](./Sqrt-x.ts#L46)

`Math.sqrt()` 함수는 숫자의 제곱근을 반환된다. 숫자가 음수이면 `NaN`를 반환한다.

```javascript
Math.sqrt(x);
```

> - x: 숫자

```javascript
Math.sqrt(9); // 3
Math.sqrt(2); // 1.414213562373095

Math.sqrt(1); // 1
Math.sqrt(0); // 0
Math.sqrt(-1); // NaN
```
